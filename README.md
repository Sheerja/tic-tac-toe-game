# 🎮 Tic Tac Toe Game

A responsive Tic Tac Toe game built using **HTML5**, **CSS3**, and **JavaScript**. The game supports two-player gameplay with score tracking, winner detection, draw detection, and a clean responsive interface.

## 🚀 Features

* Two-player gameplay
* Real-time turn indicator
* Win detection
* Draw detection
* Score tracking
* Reset current game
* Start a new game
* Winning combination highlighting
* Responsive design for desktop, tablet, and mobile

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
